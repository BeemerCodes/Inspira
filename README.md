# Inspira - Projeto acadêmico

## Sobre o Projeto

Projeto desenvolvido para a disciplina de Design Web. O projeto consiste em uma biblioteca digital fictícia desenvolvida como um site estático, utilizando exclusivamente HTML e CSS, sem a utilização de JavaScript.

A implementação da interface e a hierarquia dos elementos foram desenvolvidas com base nos wireframes previamente elaborados e nas boas práticas de estruturação e estilização ensinadas na disciplina.
